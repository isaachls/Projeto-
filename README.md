# Projeto Bremster
Sistema web de pedidos num brechó. O cliente vê peças e faz o pedido pelo celular e retira no local, melhorando separação de peças e evitando superlotação no ambiente.

## Funcionalidades 
- Cadastro e login de clientes
- Catálogo com preços e fotos 
- Filtro de seleção para cor e tamanho.
- Utilização de cupons.
  
## Tecnologias 
- PHP 8.2 
- MySQL 8 
- HTML, CSS e JavaScript 
- XAMPP (ambiente local) 
## Como rodar 
1. Instale o XAMPP e ligue Apache e MySQL. 
2. Copie a pasta `Projeto-` para `C:\xampp\htdocs`. 
3. No phpMyAdmin, importe `database/banco_bremster_.sql`. 
4. Acesse http://localhost/Projeto-
Passos detalhados em `docs/instalacao.md`.
